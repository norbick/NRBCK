# XAERO // Chroma Carnival

Szalony, kompletnie niepraktyczny eksperyment estetyczny zbudowany w Astro.

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Gdzie edytować

- `src/pages/index.astro` - cała kompozycja wizualna
- `src/layouts/Layout.astro` - meta, HTML shell, podstawowy layout
