# XAERO - Astro Practice

This repository contains a starter Astro project for learning.

## Start

```bash
npm install
npm run dev
```

Open `http://localhost:4321`.

## Useful commands

```bash
npm run dev
npm run build
npm run preview
```

## Notes

- Main page: `src/pages/index.astro`
- Reusable components: `src/components`
- Static files: `public`
